# Pantry App Design System

Welcome to the Pantry App component library. This Storybook documents all UI components used in the application, organized following **Atomic Design** principles.

## Atomic Design Structure

### Atoms
The foundational building blocks - individual UI elements that cannot be broken down further:
- **Button** - Primary action buttons with multiple variants
- **Input** - Text input fields with labels and validation states
- **Card** - Container components for grouping content
- **Icons** - Custom SVG icons for food items and locations

### Molecules
Combinations of atoms that form simple UI components:
- Form fields with labels and validation
- Search bars
- Category chips/tags

### Organisms
Complex components composed of molecules and atoms:
- **FoodItemCard** - Displays food item with category, quantity, location, and expiration
- **Header** - App header with navigation
- **BottomNav** - Bottom tab navigation

### Templates
Page-level layout structures (coming soon)

### Pages
Full page implementations:
- **InventoryPage** - Main pantry view with filtering and sorting
